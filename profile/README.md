## ✨ About us

**Neyam OpenSc** is a home for free and open source software made with people in mind.
We build tools that are simple to use, write code that is easy to read,
and keep our communities welcoming to everyone — from first-time
contributors to seasoned maintainers.

No gatekeeping. No black boxes. Just good software, built in the open.

## 🤝 Get involved

We'd love your help — no contribution is too small.

1. **Explore** our [repositories](https://github.com/orgs/Neyam-OpenSc/repositories) and find something you care about.
2. **Start small** — look for issues labeled [`good first issue`](https://github.com/search?q=org%3ANeyam-OpenSc+label%3A%22good+first+issue%22+state%3Aopen&type=issues).
3. **Say hello** — open a [discussion](https://github.com/orgs/Neyam-OpenSc/discussions) or an issue; we're friendly.
4. **Read the guides** — every project ships a contributing guide and code of conduct so you always know where you stand.

<sub>Be kind. Be curious. Ship good things.</sub>
